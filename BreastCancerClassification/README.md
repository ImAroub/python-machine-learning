# Machine Learning Project: Breast Cancer Classification

## Overview
This project demonstrates the application of Machine Learning techniques to classify breast cancer tumors as **malignant** or **benign** using a real-world dataset obtained from **Kaggle**.  
The project focuses on building a complete Machine Learning pipeline, from data preprocessing to model evaluation.

## Dataset
- **Source:** Kaggle – Breast Cancer Dataset
- **File:** `Breast_cancer_data.csv`
- The dataset includes multiple numerical features extracted from breast cancer cell images, along with a target label indicating the diagnosis.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- PyCharm

## Approach
1. Loading and exploring the dataset
2. Preprocessing the data and preparing features
3. Training a Machine Learning classification model
4. Evaluating model performance using appropriate metrics
