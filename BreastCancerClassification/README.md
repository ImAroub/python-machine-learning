# Breast Cancer Classification

A machine learning project for classifying breast tumors as **malignant or benign** using numerical tumor features.

The project compares **Logistic Regression** and **Random Forest**, with data preprocessing and model evaluation.

## Workflow

- Data exploration and missing-value handling
- Feature standardization using `StandardScaler`
- Train/test split
- Logistic Regression and Random Forest training
- Model comparison using classification metrics
- Confusion Matrix
- ROC Curve and AUC
- Random Forest tuning using `GridSearchCV`

## Technologies

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Dataset

The project uses `Breast_cancer_data.csv`, where:

- `0` = Malignant
- `1` = Benign

## Academic Context

Developed as part of university coursework to practice machine learning classification and model evaluation.
