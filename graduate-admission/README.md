# Graduate Admission Prediction

A machine learning project that uses **Linear Regression** to predict a student's chance of graduate admission.

The model uses:

- GRE Score
- TOEFL Score
- CGPA
- Research Experience

## Workflow

- Data preparation
- Train/test split
- Feature standardization
- Linear Regression
- Prediction and model evaluation
- Actual vs. predicted comparison
- Data visualization

## Evaluation

The model is evaluated using:

- MAE
- MSE
- R² Score

## Technologies

- Python
- Pandas
- Scikit-learn
- Matplotlib
