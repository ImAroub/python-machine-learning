# Seeds Dataset Clustering

A machine learning project that applies **K-Means clustering** to a wheat seeds dataset based on geometric measurements.

## Workflow

- Data preprocessing
- Feature standardization using `StandardScaler`
- K-Means clustering with three clusters
- PCA for dimensionality reduction
- 2D visualization of the resulting clusters
- Comparison of feature averages across clusters

The original class labels are excluded from the clustering features.

## Technologies

- Python
- Pandas
- Scikit-learn
- Matplotlib
