# Python Machine Learning

A collection of machine learning projects developed in Python, covering **classification, clustering, and regression**.

## Projects

### Breast Cancer Classification

A classification project that compares **Logistic Regression** and **Random Forest** to classify breast tumors as malignant or benign.

Includes data preprocessing, model evaluation, ROC/AUC analysis, confusion matrices, and Random Forest hyperparameter tuning.

[View Project](./BreastCancerClassification)

---

### Seeds Dataset Clustering

An unsupervised learning project that applies **K-Means clustering** to a wheat seeds dataset.

Includes feature standardization, PCA dimensionality reduction, cluster visualization, and analysis of cluster characteristics.

[View Project](./SeedsDatasetClustering)

---

### Graduate Admission Prediction

A regression project that uses **Linear Regression** to predict a student's chance of graduate admission based on academic features.

Includes preprocessing, model training, prediction, and evaluation using MAE, MSE, and R².

[View Project](./graduate-admission)
